# To-Do apps: Flask and Django

The same to-do app built twice, so you can compare the two frameworks.

| Folder         | Stack                              | Dependencies |
|----------------|------------------------------------|--------------|
| `flasktodo/`   | Flask + SQLite (`sqlite3`)         | Flask        |
| `djangotodo/`  | Django + Django ORM + built-in auth | Django       |

Both have: sign up, log in / log out, add / edit / delete / complete tasks, priority,
due dates, overdue highlighting, search, filters, sorting, clear completed, change
password and delete account. Each app has its own `README.md` with setup steps.
